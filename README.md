# The Solitaire Group website

Static website for The Solitaire Group, hosted with GitHub Pages.

- Repository: https://github.com/devanshmahar/solitaire-real-state-website-
- Website: https://devanshmahar.github.io/solitaire-real-state-website-/
- Deployment: GitHub Pages publishes the `/(root)` folder from the `main` branch.

The site is plain HTML, CSS, JavaScript, and static media; it does not need a build step or server. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/(root)`.

Search engines are directed by `robots.txt` to the published `sitemap.xml`, which lists the home, current projects, and completed projects pages. Page titles, descriptions, canonical URLs, social previews, and organization details are maintained in each page's HTML.
