# The Solitaire Group website

Static website for The Solitaire Group, hosted with GitHub Pages.

- Repository: https://github.com/devanshmahar/solitaire-real-state-website-
- Website: https://devanshmahar.github.io/solitaire-real-state-website-/
- Deployment: pushes to `main` run the **Deploy website to GitHub Pages** workflow.

The site is plain HTML, CSS, JavaScript, and static media; it does not need a build step or server. The repository's **Settings → Pages** source must be set to **GitHub Actions**.
